# ทำคลิป Intro เองฟรี (ไม่เสียเครดิต Higgsfield และไม่ใช้ Claude)

เครื่องมือนี้สร้างคลิป intro แบบ motion graphic จากโลโก้ของคุณด้วยโค้ดล้วน ๆ (ไม่ใช้ AI)
ได้วิดีโอ 1920×1080, 30fps, 5 วินาที, มีเสียงประกอบ ครบ 10 สไตล์

| สไตล์ | ลักษณะ |
|---|---|
| `snatch` ⭐ | กระต่ายกับตัวหนังสือแยกชิ้น: ตัวหนังสือกระแทกขึ้น กระต่ายพุ่งตะปบ เหรียญแตก กระต่ายฉกหนี (ใช้ไฟล์ใน `intro/layers/`) |
| `energy` | เส้นแสงพุ่งเข้า โลโก้กระแทก ฟ้าแลบ เหรียญหมุน ซูมทะลุ |
| `glitch` | ภาพแตกดิจิทัล สีเหลื่อม ปิดจอแบบทีวีเก่า |
| `claw` | กรงเล็บข่วนฉีกจอเผยโลโก้ เหรียญตกกระหน่ำ จอแยกสองท่อน |
| `comic` | การ์ตูนมังงะ ฮาล์ฟโทน ดาวระเบิด ตัวอักษร SNATCH! วงกลมปิดจอ |
| `portal` | วงเวทวาดตัวเอง แสงระเบิด โลโก้ค่อย ๆ ปรากฏ ลึกลับ |
| `neon` | ป้ายไฟนีออนบนผนังอิฐ ไฟกะพริบติด เสียงหึ่ง ดับตอนจบ |
| `pixel` | เกมตู้ 8-bit: INSERT COIN, หยอดเหรียญ, โลโก้คมขึ้นจากพิกเซล, เพลงชิปทูน |
| `splash` | สาดสีม่วง/ส้มบนกระดาษ โลโก้เด้ง สีไหลย้อย สาดปิดจอตอนจบ |
| `minimal` | เรียบหรู เส้นกรอบวาดตัวเอง โลโก้เลื่อนขึ้น เปียโนเบา ๆ |

## วิธีที่ 1: กดบน GitHub (แนะนำ ใช้มือถือได้)

1. เปิด repo นี้บน GitHub → แท็บ **Actions** → เลือก **Make intro clip** ทางซ้าย
2. กด **Run workflow** (ปุ่มขวามือ)
3. กรอก
   - **logo**: ค่าเริ่มต้น `intro/logo.png` คือโลโก้ The Snatchers ที่อยู่ใน repo แล้ว ไม่ต้องแก้
     — ใช้โลโก้อื่น: ใส่ลิงก์ Google Drive (แชร์แบบ "ทุกคนที่มีลิงก์") หรือลิงก์รูป PNG
   - **styles**: `all` (ทั้ง 10 แบบ) หรือเลือกเฉพาะ เช่น `claw,neon,minimal`
   - **name**: ชื่อไฟล์ เช่น `snatchers`
4. กด **Run workflow** สีเขียว รอประมาณ 2–4 นาที
5. คลิกที่รายการที่รันเสร็จ (เครื่องหมาย ✅) → เลื่อนลงไปที่ **Artifacts** → ดาวน์โหลดไฟล์ zip
   ข้างในมีวิดีโอ `.mp4` ทุกสไตล์ และภาพตัวอย่าง `_preview.jpg`

> repo นี้เป็น public จึงใช้ GitHub Actions ได้ฟรีไม่จำกัด (ถ้าเปลี่ยนเป็น private จะได้ฟรีเดือนละ 2,000 นาที
> รันหนึ่งครั้งใช้ราว 3–5 นาที) — ไฟล์ที่ดาวน์โหลดจาก Artifacts ของ repo public คนอื่นก็ดาวน์โหลดได้เช่นกัน

## วิธีที่ 2: รันในคอมพิวเตอร์

```bash
pip install pillow numpy imageio-ffmpeg
python3 intro/mograph/make_intro.py --logo logo.png --styles all --out out
```

## เคล็ดลับ

- ใช้ PNG พื้นหลังโปร่งใส ถ้าพื้นหลังทึบ โลโก้จะเป็นกรอบสี่เหลี่ยม
- อยากปรับจังหวะ/สี แก้ค่าคงที่ด้านบนของไฟล์สไตล์ใน `intro/mograph/` (เช่น `IMPACT`, `BEATS`, `ORANGE`)
